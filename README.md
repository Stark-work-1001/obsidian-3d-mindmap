# 3D Mind Map（obsidian-3d-mindmap）

把当前笔记的大纲层级渲染成可交互的 **3D 思维导图**：节点可以在 3D 里直接增删改，改动实时写回 Markdown；笔记在编辑器里的改动也会实时刷新到 3D 图。一篇笔记就是一张导图，没有额外的中间文件。

- 最低 Obsidian 版本：1.4.0（桌面端为主，移动端可用但未做专门优化）
- 公式渲染在本地完成，插件运行期间不联网

## 功能一览

- **3D 交互导图**：轨道旋转 / 平移 / 缩放；悬停球体浮出备注卡片；双击聚焦到子树；左侧只读大纲预览；点 Obsidian 右侧大纲面板的标题可直接在 3D 里定位那一节。
- **二十种布局**：收进工具条一颗下拉按钮，按原型分组直选，每档带一句读法（清单见下）。
- **3D 内编辑 + 双向实时同步**：建子级、建同级、改标题、写备注、删除、缩进升降级、同级移动、撤销重做，全部写回 Markdown 源文件；所有编辑都是补丁式写回，正文、表格、代码块、frontmatter 不会被改动。
- **标题牌与一级标题环线**：文档名称不占节点，只在画布上方显示为标题牌；各一级标题按文档序连成一圈，体现并列结构。
- **级别规则**：`#` 的个数就是节点级别（`######` = 第 6 级），跳级不报错、层级照样拉开。
- **公式与备注**：`$...$` / `$$...$$` 公式排版渲染；节点备注（`>` 引用块）悬停浮卡、右侧面板编辑与预览。
- **重点管理**：节点钉住持续发光（手动钉 + 按文本规则自动钉）；按标签或文本规则给球着色、隐藏子树；任意两个节点之间可手拉一条关联弧线。
- **外观调节**：全局与单节点球径、连线粗细 / 线型 / 颜色 / 长度、辉光与荧光强度、背景预设 / 渐变 / 自定义色、标签自动避让。
- **导出**：一键导出 PNG，落在当前笔记同目录。
- **视图状态按笔记保存**：相机位姿、布局、折叠、聚焦按文件路径存放，重开恢复；笔记改名自动迁移，删除自动清理。

### 二十种布局

| 分组 | 布局 |
| --- | --- |
| 物理原型组 | 力导向、径向展开、层级树、键角树（分子）、羽状纤维束（肌）、RDF 壳层（液体）、能级壳层（玻尔+泡利）、轨道瓣、无规线团（聚合物）、金刚石格点（晶体） |
| 参考图组 | 圆锥塔、星系盘、射线串珠、星芒社区、层板、垂帘、蒲公英球、点阵填充、星云团簇、星尘（下拉菜单内按星系型 / 放射型 / 分层型 / 矩阵型 / 零散型再分组） |

物理原型组适合常规结构化笔记：力导向用于探索、径向展开读层级、层级树看纵深，其余各档按对应的物理原型落位；参考图组提供更风格化的整体形态。

## 安装

1. 把 `main.js`、`manifest.json`、`styles.css` 和 `vendor/` 文件夹复制到
   `<你的库>/.obsidian/plugins/obsidian-3d-mindmap/`（目录不存在就新建）。
   **公式渲染需要 `vendor/katex/`（样式表 + 字体文件）**：不复制它插件也能用，但公式会显示成原文。
2. Obsidian → 设置 → 第三方插件 → 关闭「受限模式」→ 启用 **3D Mind Map**。

## 打开导图

三选一：

- 点击左侧栏的**网络图标**；
- 命令面板（`Ctrl + P`）→ `3D Mind Map: 以 3D 思维导图打开当前笔记`；
- 快捷键 `Ctrl + Shift + M`（在新标签页打开）。

视图跟随当前活动笔记：切换笔记时 3D 图自动重绑；也可用工具条「关联文档…」把视图改绑到任意一篇 Markdown。

## 相机操作

| 操作 | 效果 |
| --- | --- |
| 鼠标中键拖拽 / Shift + 左键拖拽 | 轨道旋转 |
| 右键拖拽 / 左键拖空白 | 平移 |
| 滚轮 | 缩放 |
| 左键点击节点 | 选中（高亮 + 右侧备注面板） |
| 左键拖拽节点 | 移动该节点（只改 3D 空间位置，不改文档层级） |
| 光标悬停节点 | 浮出备注卡片 |
| 双击节点 / 双击空白 | 聚焦子树 / 退出聚焦 |
| 触屏单指 / 双指 | 旋转 / 缩放 |

工具条「视角」按钮切换旋转中心：自由旋转 / 绕全图质心 / 绕选中节点。

## 在 3D 里编辑

选中节点后：

| 按键 | 效果 |
| --- | --- |
| `Tab` / `Enter` | 新建子节点 / 同级节点 |
| `Shift + Enter` | 打开备注面板 |
| `F2` | 聚焦该子树 |
| `Space` | 折叠 / 展开 |
| `Delete` | 删除节点及其子树 |
| `[` / `]` | 减少 / 增加缩进（升降级） |
| `Alt + ↑ / ↓` | 同级上移 / 下移 |
| `↑ ↓ ← →` | 移动选择 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |
| `Ctrl + F` | 视图内搜索（命中高亮，其余淡出） |

所有编辑实时写回 Markdown：新建标题会按父级自动写成合适的 `#` 档或缩进列表项，空节点会被自动清掉，不会在源文件里留下空行。

## 笔记怎么写

| 语法 | 在导图里 |
| --- | --- |
| `#`–`######` 标题 | 节点，`#` 的个数 = 级别 |
| 标题下的列表项（按缩进嵌套） | 挂在该标题下的节点 |
| 节点行下方同缩进的 `> ` 引用块 | 该节点的备注 |
| `$...$` / `$$...$$` | 排版渲染的公式（代码块内的 `$` 不算公式） |
| `- [ ]` / `- [x]` | 任务节点（显示 ☐ / ☑） |

文档名称默认只显示在标题牌上。想让核心显示别的名字，两条路都是写进文件自己的声明：

1. frontmatter 里写 `mindmap-root: 名字`；
2. 文件名里用全角 `｜` 隔开，如 `读书笔记｜精校版.md` 显示为「读书笔记」。

## 常用设置（节选）

| 设置 | 说明 |
| --- | --- |
| 默认布局 | 二十档任选，工具条下拉可随时换 |
| 节点大小倍率 | 0.10–6.00；可对选中的单个节点单独覆盖 |
| 连线粗细 / 线型 / 颜色 / 长度 | 实线、划线、点线、点划线四种线型；「长度」一键张开或收拢整图 |
| 自动钉住规则 | 按关键词（包含 / 前缀 / 后缀 / 正则）命中即发光，开图自带重点 |
| 分组着色与过滤 | 按标签或文本规则改球色、隐藏子树（只影响视图，不改文档） |
| 辉光 / 荧光强度 | 0 为完全关闭 |
| 标签 | 自动避让、同屏上限、可见距离；全部关掉可提高大图帧率 |
| 背景 | 跟随主题 / 单色 / 渐变，含多档预设 |
| 悬停备注 | 开关与延迟 |
| 导出 PNG | 文件名后缀 `.3d.png` |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 公式显示成 `$...$` 原文 | `vendor/katex/` 没有复制全（需要样式表和 fonts 目录），补齐后重载插件 |
| 提示「WebGL 不可用」 | 硬件加速被关闭；调整后执行命令「重载 3D 视图」，届时导图以大纲形式降级显示 |
| 大图卡顿 | 调低「同屏标签上限」，或关闭「显示节点标签」「布局动画」 |
| 改标题后钉住 / 关联线失联 | 钉住与关联按「祖先文本路径」锚定，改标题会断开；菜单会列出失联条目，重新钉一次即可 |
| 导出 PNG 里公式是普通文本 | 已知限制：PNG 里的公式以原文呈现，屏幕上看是完整排版 |
| 拖动节点后文档层级没变 | 拖拽只改 3D 空间位置；改层级请用 `[` / `]` 或 `Alt + ↑/↓` |
